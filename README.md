# Vrinda Store Annual Sales Analysis Dashboard – Excel

## 📊 Project Overview

This project is an Excel-based sales analysis and dashboard project created using the Vrinda Store 2022 sales dataset.

The dashboard provides an overview of sales performance, order trends, customer demographics, order status, sales channels, and state-wise sales performance.

The project uses Excel data analysis techniques such as PivotTables, charts, data aggregation, filtering, and dashboard visualization to transform raw sales data into meaningful business insights.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze monthly sales and order trends.
* Compare sales performance between men and women customers.
* Analyze different order statuses such as Delivered, Cancelled, Returned, and Refunded.
* Identify the top-performing states based on sales.
* Analyze customers based on age groups and gender.
* Compare sales/order contribution across different sales channels.
* Create an interactive and easy-to-understand Excel dashboard.
* Generate business insights from the available sales data.

## 📈 Dashboard & Analysis

The workbook contains multiple analysis sheets and a main dashboard.

### 1. Monthly Sales vs Orders

Analyzes monthly sales amount and number of orders to understand sales trends throughout the year.

### 2. Men's vs Women's Sales

Compares sales contribution between male and female customers.

### 3. Order Status Analysis

Analyzes orders based on their status:

* Delivered
* Cancelled
* Returned
* Refunded

### 4. Top States by Sales

Identifies the states generating the highest sales.

The analysis includes states such as:

* Maharashtra
* Karnataka
* Uttar Pradesh
* Telangana
* Tamil Nadu

### 5. Age & Gender Analysis

Analyses customer/order distribution across:

* Adult
* Senior
* Teenager

and compares the distribution between men and women.

### 6. Sales Channel Analysis

Analyses order contribution across different sales channels, including:

* Amazon
* Myntra
* Flipkart
* Ajio
* Meesho
* Nalli
* Others

## 🔍 Key Analysis Areas

The dashboard focuses on the following business questions:

1. How do sales and orders change throughout the year?
2. Which customer gender contributes more to sales?
3. What is the distribution of different order statuses?
4. Which states generate the highest sales?
5. Which age groups contribute the most orders?
6. Which sales channels generate the largest share of orders?
7. What patterns can be observed from customer and order data?

---

## 💡 Key Insights

Some observations from the analysis include:

* Women's sales contribution is higher than men's sales contribution in the analyzed dataset.
* Maharashtra and Karnataka are among the leading states by sales.
* The majority of orders are in the Delivered status.
* Amazon, Myntra, and Flipkart represent major sales channels in the dataset.
* Customer/order distribution can be analyzed effectively using age groups and gender.
* Monthly analysis helps identify changes in sales and order volume throughout the year.

> Note: These insights are based on the dataset included in this project and are intended for analytical and educational purposes.
